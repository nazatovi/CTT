\# DECISIONS



\## D-001



Fecha:

2026-07-25



Título:

Profesionalización del proyecto



Decisión:



Se establece una etapa formal de profesionalización del proyecto.



A partir de esta fecha:



\- toda nueva funcionalidad deberá respetar la arquitectura MVVM;

\- las decisiones importantes se documentarán;

\- se mantendrá un roadmap del producto;

\- se priorizará la reutilización de componentes y la mantenibilidad del código.



Motivo:



Garantizar el crecimiento ordenado del proyecto y facilitar su mantenimiento a largo plazo.
